# 🌈 Nuri Town (누리타운)
> **2019 개정 누리과정 기반 유아 맞춤형 놀이·체험 코스 설계 및 인터랙티브 놀이 월드 플랫폼**

유치원 교사가 놀이 주제·지역·견학 요일·예산을 입력하면 **LangGraph 기반 AI 에이전트**가 실제 공공 데이터를 조회·검증하여 최적의 교육 코스를 설계하고, 유아는 태블릿/PC 환경에서 캐릭터를 직접 조작하며 독서·미술·탐험 놀이를 즐길 수 있는 에듀테크 웹 서비스입니다.

---

## ✨ 주요 기능

### 1. 👩‍🏫 교사 대시보드 (`/index`, `/detail`)
- **AI 놀이 & 현장 체험 코스 자동 설계**: 희망 지역, 평일 견학 요일, 1인당 예산을 바탕으로 누리과정 연계 놀이 활동 및 현장 체험 기관을 추천합니다.
- **현실 제약 조건 검증 및 자동 재계획 (LangGraph)**:
  - 선택한 견학 요일과 체험 기관의 실제 휴무일이 겹칠 경우 대체 기관으로 자동 재조정합니다.
  - 도서 구매비 + 입장료가 설정 예산을 초과할 경우 도서관 무료 대출(0원) 전환 등 비용 절감 플랜을 자동으로 재구성합니다.
- **교사 주도형(Human-in-the-Loop) 그림책 선택**: 주제에 맞는 유아 추천 그림책 후보 3권을 제공하고, 교사가 우리 반에 적합한 도서를 직접 선택하며 지역 도서관 대출 및 도서 상세 정보를 바로 확인할 수 있습니다.
- **우리 반 원아 관리**: 반 이름 설정 및 원아별 전용 캐릭터 아바타, 누적 스탬프 현황, 지도 메모를 관리합니다.

### 2. 🧒 유아용 인터랙티브 놀이 월드 (`/play`)
- **터치 & 키보드 친화형 마을 탐험**: 화면 좌측 하단의 가상 방향 패드(`⬆️⬇️⬅️➡️`)와 키보드 방향키로 캐릭터를 이동하며 4개의 놀이 공간을 순서대로 탐험합니다.
- **4단계 맞춤형 놀이 코스**:
  1. **📚 1코스 · 누리 북카페**: 교사가 선정한 오늘의 그림책 줄거리 확인 및 한국어 음성 구연(TTS) 듣기, 주제별 그림 카드 5쌍 짝맞추기 놀이
  2. **🎨 2코스 · 누리 창작 공방**: 브러시 색상 및 스티커를 활용한 자유 그리기 및 우리 반 미술관 즉시 전시(전시 시 창작 스탬프 자동 적립)
  3. **🖼️ 3코스 · 누리 미술관**: 창작 공방 완료 시 작품이 자동 전시되며, 개별 작품을 크게 확대해 감상하고 박수 응원을 보낼 수 있는 공유 갤러리
  4. **🏛️ 4코스 · 누리 탐험 광장**: 돋보기 인터랙션을 활용해 함정 아이템을 피해 숨은 보물 5개를 찾는 관찰 놀이 및 실제 체험 기관 구경하기 연결
- **📮 꼬마 탐험가 방명록**: 기분 이모지 선택과 음성 인식(Web Speech API)을 통해 글자를 모르는 유아도 말로 방문 소감을 기록할 수 있습니다.

## 🛠️ 기술 스택

- **Backend**: Python, FastAPI, SQLite, LangGraph, LangChain (OpenAI API)
- **External APIs**:
  - 국립중앙도서관 도서관 정보나루 API (유아 추천 그림책 조회)
  - 한국관광공사 TourAPI (지역 어린이 체험·문화시설 및 휴무일·요금 조회)
  - Kakao 도서 검색 API (도서 가격 및 줄거리 정보 보강)
- **Frontend**: HTML5, CSS3, Vanilla JavaScript, HTML5 Canvas, Web Speech API (TTS / STT)

## 🚀 실행 방법

### 1. 가상환경 생성 및 패키지 설치

```bash
python -m venv venv
source venv/Scripts/activate  # Windows Git Bash 기준 (Mac/Linux: source venv/bin/activate)
pip install -r requirements.txt
```

### 2. 환경 변수 설정 (`.env`)
```env
OPENAI_API_KEY=your_openai_api_key
DATA4LIBRARY_API_KEY=your_data4library_api_key
TOUR_API_KEY=your_tour_api_key
KAKAO_REST_API_KEY=your_kakao_rest_api_key
```

### 3. 서버 실행
```
uvicorn app.main:app --reload
```

## 🛠️ 트러블슈팅 & 기술적 개선 기록 (Troubleshooting)

### 1. Web Speech API(TTS) 장문 낭독 시 음성 끊김 현상 해결
* **문제 상황**: 1코스(누리 북카페)에서 그림책 줄거리를 한국어 음성(TTS)으로 읽어줄 때, 줄거리가 150~200자를 넘어가면 브라우저 내장 `speechSynthesis` 엔진 특성상 낭독이 중간에 갑자기 멈추는 현상이 발생했습니다.
* **해결 방법**: 전체 줄거리를 한 번에 `SpeechSynthesisUtterance`에 전달하지 않고, 정규표현식(`/(?<=[.!?])\s+/`)을 이용해 **문장 단위로 청크(Chunk) 분할**한 뒤 `onend` 이벤트를 체이닝하여 순차 낭독하도록 개선해 긴 동화 줄거리도 끊김 없이 끝까지 재생되도록 해결했습니다.

### 2. 외부 쇼핑 도메인 접근 제한(봇 차단) 우회 및 검색 안정화
* **문제 상황**: 교사 대시보드에서 추천 그림책의 상세 보기를 클릭할 때 특정 쇼핑 검색 도메인(`search.shopping.naver.com`)으로 연결하면 짧은 시간 내 다수 요청 시 일시적 접근 제한 페이지가 노출되는 문제가 있었습니다.
* **해결 방법**: 외부 도메인 차단 정책에 영향을 받지 않도록 일반 통합 검색 엔드포인트(`search.naver.com`) 기반 도서·도서관 조회 링크로 전환하여 교사가 언제든 안정적으로 도서 정보와 지역 도서관 대출 여부를 확인할 수 있도록 개선했습니다.

### 3. 하드코딩된 테마 한계 극복을 위한 LLM 기반 다이내믹 월드 설계
* **문제 상황**: 초기 프로토타입에서는 놀이 주제(`공룡`, `우주`, `바다` 등)에 따른 미니게임 카드 아이콘을 조건문(`if-else`)으로 매핑하여, `"봄에 오는 황사"`, `"시장 놀이"`처럼 교사가 자유롭게 입력하는 세부 주제에 유연하게 대응하지 못하는 한계가 있었습니다.
* **해결 방법**: LangGraph 에이전트(`planner_graph.py`)의 최종 생성 단계에서 LLM이 주제의 세부 맥락을 해석해 **월드 배경 컬러 팔레트, 배경 오브젝트, 카드 짝맞추기 5쌍, 숨은 보물 5개, 창작 스티커 4종**을 구조화된 JSON(`world_theme`)으로 동적 생성하도록 아키텍처를 확장했습니다. (API 장애 시에도 서비스가 중단되지 않도록 안전 폴백 데이터를 함께 구성)

### 4. EventBus 발행·구독 패턴 기반 실시간 멀티플레이 알림 구현
* **문제 상황**: 여러 기기(태블릿·PC)에서 유아가 동시에 접속해 활동할 때, 다른 친구가 미술관에 작품을 전시해도 새로고침 전까지는 즉시 인지하기 어려웠습니다.
* **해결 방법**: 에이전트 및 핵심 비즈니스 로직과 부가 기능을 분리하는 **EventBus(Pub/Sub)** 패턴을 도입하고, FastAPI의 **SSE(Server-Sent Events)** 스트림(`/api/events/stream`)과 연결하여 작품 등록 이벤트 발행 즉시 접속 중인 모든 유아 화면에 실시간 알림 토스트가 송출되도록 구현했습니다.
