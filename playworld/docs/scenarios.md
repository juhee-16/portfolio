# 누리타운(Nuri Town) 대표 시나리오 검증 보고서

## 1. 검증 개요
- **검증 대상**: 2019 개정 누리과정 연계 AI 놀이·현장 체험 설계 에이전트 (LangGraph 기반)
- **검증 범위**:
  1. 제약을 한 번에 충족하는 요청
  2. 재계획(Re-planning)이 필요한 요청
  3. 재계획 상한에 도달하는 요청
  4. 외부 Tool/검색 결과가 실패·미매칭되는 요청
  5. 외부 Tool 호출이 불필요한 단순 조회 요청

---

## 2. 대표 시나리오별 검증 결과

### 시나리오 1 · 제약을 한 번에 충족하는 요청
- **입력 조건**: 놀이 주제 `공룡과 자연`, 희망 지역 `용인`, 견학 예정 요일 `수요일`, 1인당 예산 `15,000원`[cite: 1]
- **실행 결과**:
  - 코스명: `공룡과 자연 탐험`[cite: 2]
  - 추천 그림책: `(퀴즈!) 과학상식 :공룡` (`8,550원`, 구매)[cite: 2]
  - 현장 체험 기관: `경기도어린이박물관` (휴무일: `매주 월요일`, 입장료: `2,000원`)[cite: 2]
  - 총 비용: `10,550원` (설정 예산 `15,000원` 이내 충족)[cite: 2, 3]
- **실행 로그**: `planner.start` → 정보 수집(도서 3권, 체험 공간 2곳) → 제약 검증 통과 → 최종 완성 → `planner.end` (`POST /api/plans/generate 200 OK`)[cite: 3, 4]
- **기대 vs 실제 차이**: 차이 없음 (재계획 없이 1회 만에 정상 생성 및 저장 완료)[cite: 2, 3, 4]
- **증빙**: `pictures/scenarios1/`

### 시나리오 2 · 재계획이 필요한 요청
- **입력 조건**: 휴무일(`월요일`) 충돌 또는 예산 초과 조건(도서 구매 시 예산 초과)
- **실행 결과**:
  - 1차 제약 검증에서 휴무일 충돌 또는 예산 초과 감지 후 `replan_adjust` 노드 실행
  - 도서 구매 대신 **도서관 무료 대출(`0원`)**로 전환하거나 휴무일이 겹치지 않는 대체 체험 공간으로 자동 재조정하여 제약 통과
- **실행 로그**: `제약 검증 실패` → `자동 재계획 #1` → 재검증 통과 → `최종 완성`
- **기대 vs 실제 차이**: 정상적으로 재계획 루프가 동작하여 현실 제약을 해결한 최종 코스를 반환함
- **증빙**: `pictures/scenarios2/`

### 시나리오 3 · 재계획 상한에 도달하는 요청
- **입력 조건**: 1회 재조정으로 해결되지 않거나 극단적으로 낮은 예산(`0원` 등) 조건
- **실행 결과**:
  - `should_replan` 조건(`retry_count < 2`)에 따라 최대 재계획 횟수 도달 시 무한 루프 없이 종료되고, 사유 및 대체 기본 코스와 함께 응답 반환
- **실행 로그**: `자동 재계획 #1` → `자동 재계획 #2` → 상한 도달 후 안전 종료 및 계획 확정
- **기대 vs 실제 차이**: 무한 반복 없이 정해진 재계획 상한 내에서 안정적으로 응답함
- **증빙**: `pictures/scenarios3/`

### 시나리오 4 · Tool 하나가 실패(미매칭)하는 요청
- **입력 조건**: 존재하지 않는 가상 지역명(`대서` 등) 및 미매칭 키워드 입력[cite: 8, 9]
- **실행 결과**:
  - 외부 지역 검색 결과가 비거나 실패하더라도 전체 서비스가 중단되지 않고 기본 대체 공간(`대서 시립어린이도서관`, 주소: `대서시 중앙공원길 25`, 무료)으로 폴백되어 정상 응답 반환[cite: 8, 9]
- **실행 로그**: 정보 수집 단계에서 빈 결과 감지 → 기본 대체 공간 폴백 적용 → 제약 검증 통과 → 코스 생성 완료[cite: 9]
- **기대 vs 실제 차이**: 서비스 중단 없이 대체 경로로 이어졌으며, 추후 실제 공공데이터 미매칭 시 안내 문구 명확화 필요[cite: 8, 9]
- **증빙**: `pictures/scenarios4/`

### 시나리오 5 · Tool이 필요 없는 요청
- **입력 조건**: 외부 도서·체험 API 호출이 불필요한 단순 상태·목록 조회 요청 (`GET /api/events/logs`, `GET /api/plans`)[cite: 10, 11]
- **실행 결과**:
  - 불필요한 외부 Tool 호출 없이 저장된 이벤트 로그(`[]`) 및 탐험 코스 목록 JSON이 `200 OK`로 즉시 반환됨[cite: 10, 11]
- **실행 로그**: 외부 API 호출 이벤트 미발생, 단순 조회 엔드포인트 정상 처리[cite: 10, 11]
- **기대 vs 실제 차이**: 차이 없음[cite: 10, 11]
- **증빙**: `pictures/scenarios5/`

## 3. 검증 중 발견한 문제 및 개선 내역
1. **체험 기관 주제 연관성 부족 및 요금 표기 불일치**
   - **현상**: `'반짝이는 우주탐험'` 주제 요청 시 주제와 무관한 `용인농촌테마파크`가 추천되고, 실제 유료 시설임에도 입장료가 `0원`으로 표시됨[cite: 5, 6].
   - **원인**: 지역 조회 결과의 첫 번째 항목(`places[0]`)을 주제 적합도 검증 없이 그대로 선택하는 구조였음.
   - **조치**: `planner_graph.py`에 `_score_place_for_theme()` 정렬 로직을 추가하여 주제 키워드(우주·별·천문·과학·바다·공룡 등)와 연관된 체험 기관이 우선 선택되도록 수정함.
2. **도서 후보 내 장편동화·학습상식 도서 혼입**
   - **현상**: `'반짝이는 우주 탐험'` 검색 시 유아 그림책 외에 `장편동화`, `쿠키런 과학 상식` 등 초등 대상 도서가 상위 후보에 포함됨[cite: 7].
   - **원인**: 도서 검색 결과를 유아 연령 적합도 기준 없이 API 반환 순으로 사용함.
   - **조치**: `planner_graph.py`에 `_score_book_for_toddler()` 점수 정렬을 추가하여 `그림책·유아·동화` 키워드에 가점을 주고 `장편동화·과학 상식·학습만화` 등에 감점을 주어 유아 그림책이 우선 추천되도록 개선함.
